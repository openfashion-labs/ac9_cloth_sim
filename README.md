# AC9 Cloth Sim

[English](README.en.md)

Blender の中で服の型紙を読み込み、縫い合わせ、アバターに着せて、布の落ち着き方を物理シミュレーションで確かめるアドオンです。
型紙を直して、もう一度着せて確かめる、という往復を Blender の中だけで行えます。

<!-- screenshot: 型紙 → 縫う → 着た服、の 3 枚か短い動画（GIF） -->

- 型紙を読み込む: 3D の服のソフトが書き出した型紙（CLO が書き出した `BOM.xml`）、DXF、UV シームを入れた 3D のメッシュ。ゼロから描くこともできます。
- 型紙を直す・描く: 角や辺をつかんで動かす、ダーツ、切り開き、合印、左右対称の編集など。
- 縫って着せる: 型紙を体のまわりに置き、段階を踏んで縫い合わせて着せます。止めるまで回り続けるモードでは、布を手でつまんで直せます。
- 生地: ピースごとに生地（硬さ・重さ）を選べます。芯地、ゴム、ボタンも扱えます。
- 次の工程へ: 着せた服を、同じ AC9 の [AC9 Cloth Retopo](https://github.com/openfashion-labs/ac9_cloth_retopo) に Guide として渡せます。

無料で、商用でも自由に使えます（GPL-3.0-or-later）。

## α版について

いまは **α版（0.1）** です。次のことを承知のうえでお使いください。

- 機能はまだ足りません。
- 画面と手順は、これからも変わります。
- 保存したデータ（.blend）が、次の版で開けないことがあります。
- 同じ設定でも、計算のたびに仕上がりが少し変わります。1 回の結果だけで良し悪しを決めないでください。

## 動作環境

| 項目 | 必要なもの |
|---|---|
| パソコン | Windows（64 ビット）。**Mac では動きません。** |
| GPU | **NVIDIA 製**（GeForce RTX など）。ドライバは新しいものにしてください。 |
| Blender | **5.2** |
| 空き容量 | 1 GB 程度 |

服を着せる計算に NVIDIA の GPU を使います。NVIDIA 製でないと、計算のボタンが動きません。
GPU の確かめ方: タスクマネージャーを開き、「パフォーマンス」の「GPU」に「NVIDIA」と出ているかを見ます。

## インストール

1. 配布されている ZIP ファイル（`ac9_cloth_sim-…zip`、約 190 MB）を、**展開せずに**そのまま置きます。
2. Blender 5.2 を起動し、「編集」→「プリファレンス」（Edit → Preferences）を開きます。
3. 左の一覧で「アドオン」（Add-ons）を選び、右上の小さな「∨」から「ディスクからインストール…」（Install from Disk...）を選びます。
4. ZIP ファイルを選んで、右下の「ディスクからインストール」を押します。大きいファイルなので、終わるまで少し待ちます。
5. アドオンの一覧に「AC9 Cloth Sim」が出て、チェックが入っていれば完了です。

入ったかどうかは、3D ビューポートで **N** キーを押して出るサイドバーに「**AC9 Cloth Sim**」のタブがあるかで確かめます（日本語表示でも、このタブの名前は英語のままです）。

- 新しい版を入れたときは、**Blender をいったん閉じて、起動し直してください。** 閉じずに使うと、前の版の部品が残ってエラーが出ることがあります。
- 日本語で使うときは、プリファレンスの「Interface」→「Translation」で日本語を選びます。このアドオンのボタンも日本語になります（一部は英語のままです）。
- はじめて着せるときは、GPU の準備のため、計算が始まるまで少し待ちます（数十秒ほど。パソコンによって変わります）。2 回目からは早くなります。

## はじめての 1 着（あらまし）

ボタンの名前は、日本語表示の名前と、英語表示の名前（括弧の中）を並べて書いています。詳しい手順は[説明書](#説明書)にあります。

1. **最初に .blend を保存します。** 計算の経過は、保存した .blend の隣のフォルダに作られます（保存していないと一時フォルダになり、あとで再生できません）。
2. アバター（体）を読み込みます。まっすぐ立って、正面が −Y を向いている前提です。手元に無ければ、**セットアップ**（Setup）の「**アバターを追加**」（Add Avatar）で付属のアバター（CC0）を足せます。
3. サイドバーの「AC9 Cloth Sim」タブで、**セットアップ**（Setup）の「**作業画面**」（Work Screen）を押すと、作業しやすい画面に切り替わります。
4. 型紙を読み込みます: 「**BOM を新規読み込み**」（Import BOM）、「**DXF を読み込む**」（Import DXF）、「**SVG を読み込む**」（Import SVG）、または 3D のメッシュから「**メッシュから**」（From Mesh）。DXF と SVG には縫い目が入っていないので、読み込んだ後に「**縫い目を追加**」（Add Seam）で縫い目を付けます。
5. **配置**（Placement）で、体のメッシュを「**体**」（Body）に選び、「**ガイド検出**」（Detect Guides）を押します。体の胴・首・腕・脚のまわりに、置く目安ができます。
6. 「**配置**」（Place）の道具で、型紙のピースを選んで目安の上を押し、ドラッグで位置を決めて離します。
7. 右下の Properties エディタの **Tool** タブ（いちばん上の AC9 Run）で、「**ライブシム**」（Live Sim）を押します。縫い目が引き寄せられ、服が体に落ち着いていきます。自動では止まらないので、落ち着いたら **Esc** で止めます。
8. 気に入らない所は、型紙を直して、もう一度「ライブシム」を押します（今の形から続けて計算します）。回っている間は、布を **Ctrl＋ドラッグ**でつまんで直せます。最初から着せ直すときは、何も選ばずに「**置いた形に戻す**」（Back to Placed）を押してから「ライブシム」です。
9. 着せた服は .blend に保存されます（**Ctrl+S**）。

### 迷いやすいところ

- **実行のボタンはサイドバーではなく、右下の Properties エディタの Tool タブ**にあります。Properties が別のタブ（Render など）になっていると見つかりません。
- **型紙は、Blender の普通の編集（編集モード、G/R/S）では直せません。** ピースを丸ごと動かすのは「**ピース全体**」（Whole Pieces）、角や辺を直すのは「**ピース編集**」（Edit Pieces）の道具です。
- **ピースの役割**（前身頃・前立て・台衿・袖・カフスなど）で、縫う順番、置き方（帯は輪に、袖は腕のまわりに並べる）、始まりの形が自動で決まります。縫い目を確かめてから、置く前に「**ピースの役割**」（Piece Roles）パネルの「**役割を提案**」（Propose Roles）を押し、確かめてほしい印の付いたピースを見直してください。くわしくは説明書の「ピースの役割と自動で決まること」にあります。
- **押せない（灰色の）ボタンは、カーソルを置くと理由が出ます。**
- **ノートパソコン**で中ボタンやテンキーが無いときは、プリファレンスの「入力」（Input）で「Emulate 3 Button Mouse」と「Emulate Numpad」にあたる項目をオンにすると、視点を動かしやすくなります。
- **日本語入力（IME）がオンだと、キーボードのショートカットが効きません。**

## うまくいかないとき

| 症状 | まず確かめること |
|---|---|
| 計算のボタンが灰色で押せない | 「体」（Body）を選んで「ガイド検出」（Detect Guides）を押したか。ボタンにカーソルを置くと理由が出ます。 |
| 「○ piece(s) not placed yet」と赤く出る | 置いていないピースがあります。「配置」（Place）で置くか、使わないピースをオフにします。 |
| 「Set the Newton Python in the add-on preferences」と出る | 配布版の ZIP から入れたか。開発用の環境では、プリファレンスの欄の指定が必要です。 |
| 画面の表記が説明書と違う、「cannot import name …」と出る | 新しい版を入れた後に、Blender を起動し直したか。 |
| 結果が毎回少し違う | α版では、同じ設定でも揺れます。何度か回して見てください。 |

ほかの症状は、説明書の「困ったとき」を見てください。
