# Overall flow

1. **Setup** — Load a pattern (**Import BOM**, **Import DXF**, or **From Mesh** for a mesh you made in 3D).
2. **Pattern** — Fix the pattern or draw a new one if needed.
3. **Seams** — Check that the seams are correct, add them, fix them.
4. **Placement** — Choose a body, make placement guides with **Detect Guides**, and put the pattern around the body with **Place**.
5. **AC9 Run** (Tool tab) — Sew and dress with **Live Sim**. Fix anything you do not like with **Back to Placed**, **Fix by Hand**, **Live Sim**, and so on, then continue.
6. **To AC9 Cloth Retopo** — Hand the result over to Cloth Retopo.
7. **Measure** — Measuring and checking sizes (any time).
