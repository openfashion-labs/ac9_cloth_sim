# Send to AC9 Cloth Retopo

This creates an `AC9_Guide_<garment name>` from the dressed garment to hand over to Cloth Retopo. The seams close exactly. The flat shape of the pattern goes into the shape key `UVMap_Flattened` (actual size). If Cloth Retopo is enabled, the add-on sets it up as that Guide automatically.

- Prerequisite: a dressed result exists.
- Steps: this uses the frame shown on screen, so normally set the timeline to the last frame first, then press **To AC9 Cloth Retopo** inside **Details**.
- Expected result: the screen shows the vertex count and how far the seams were open (before closing). If a Guide with the same name exists, it is rebuilt.
