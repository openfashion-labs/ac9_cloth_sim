# 操作の待ち時間を記録（試験中）

プリファレンスのアドオン設定で「試験中の機能」を有効にした場合だけ、「操作の待ち時間を記録」が表示されます。標準では両方とも無効です。記録を有効にし、普段どおり操作してください。起動直後を調べる場合は設定を保存してからBlenderを再起動します。「試験中の機能」を無効にすると記録も停止します。

「計測ログを開く」で、このPCに保存されたセッション別のログフォルダーを開けます。自動送信はありません。ログには読み込んだファイルのパスが含まれます。

記録するのはAC9の操作を受け付けた時刻、処理名、処理時間、プロセスのCPU時間、次の3D描画コールバックまでの時間、0.5秒以上のイベントループの間隔です。2秒以上応答が途切れると、取得できる場合は処理中の名前とPythonの呼び出し位置を残します。ロードの開始・終了と既存ソルバーログの場所も記録します。

処理の開始は終了前にファイルへ書き出します。クラッシュで終了記録が無い場合も開始記録を調べられます。ただし、強制終了やOSの停止時に全記録の保存を保証するものではありません。記録はセッション内で最大約32MiBの4ファイルを循環します。古いセッションは自動削除しません。

入力時刻はAC9の処理に入った時刻で、物理的にクリックした時刻ではありません。描画の記録は3D描画処理への到達で、モニターへの表示完了ではありません。Pythonを動かせない停止では呼び出し位置をその場で取得できず、復帰後の時間差か最後の開始記録が手掛かりになります。アドオン登録前の起動時間、他のアドオンの処理内訳、ネイティブ処理内部の原因はこの記録だけでは特定できません。

計測は処理の観測だけを行い、服や型紙、シミュレーション設定は変更しません。調査が終わったら記録を無効にしてください。
