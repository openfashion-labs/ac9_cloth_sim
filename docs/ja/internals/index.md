# 仕組み（技術メモ）

この章は、使い方の説明ではありません。AC9 Cloth Sim が裏でデータをどう持ち、いつ何を作り直しているかの説明です。

服を着せるだけなら読まなくてもかまいません。次のようなときに役に立ちます。

- 「さっきは Blender の普通の操作で動いたのに、今は動かない」のように、同じピースなのに扱いが変わって見えるとき
- ギズモが思った所に出ない、選んだはずの物が選ばれていない、のような Blender 側の振る舞いに戸惑ったとき
- スクリプトを書いて自動化したい、アドオンを改造したいとき

| ページ | 中身 |
|---|---|
| [データの持ち方](data-model.md) | 型紙のデータが 1 つあり、そこから 3 種類のオブジェクトが作られること。どれが Blender の普通の操作で触れるか |
| [選択とギズモ](selection.md) | ピースの選択がどこに記録されるか。着た服のピースを AC9 のツールでしか選べない理由。ギズモがずれるとき |
| [計算の流れと保存](simulation.md) | ボタンを押してから服の形が返るまで。何が .blend に入り、何が外のフォルダに残るか |
| [改造する人へ](for-developers.md) | ソースのどこに何があるか、守っている約束 |
| [操作の待ち時間を記録（試験中）](ui-timing.md) | Experimental限定の計測、保存先、記録から分かる範囲 |

使う側から見た説明は「[考え方](../concepts.md)」にあります。この章はその裏側です。
