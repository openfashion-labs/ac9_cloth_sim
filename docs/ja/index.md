# AC9 Cloth Sim 説明書

この原稿は **0.5.0の公開候補**です。正式公開は0.4.0で、この候補はまだ配布していません。完成済みの設定・形・診断の画像を収録しています。

英語版でも一部は日本語UIの画像を共用し、英語の見出しと本文で操作を説明しています。すべての画像を英語UIで撮影したものではありません。

Blender の中で服の型紙を読み込み、縫い合わせ、アバターに着せて、布の落ち着き方を確かめるアドオンの説明書です。
いまは **α版** です。インストールした版に対応する説明書を使ってください。機能は足りず、画面と手順はこれからも変わります。

## ボタンの名前の書き方

Blender を日本語表示にしていると、このアドオンのボタンも日本語で出ます。この説明書では、**日本語表示の名前**を先に書き、**英語表示の名前**を括弧の中に書きます（例: 「シミュレート」（Simulate））。一部のボタンは、日本語表示でも英語のままです。
