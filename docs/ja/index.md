# AC9 Cloth Sim 説明書

Blender の中で服の型紙を読み込み、縫い合わせ、アバターに着せて、布の落ち着き方を確かめるアドオンの説明書です。
いまは **α版（0.1）** です。機能は足りず、画面と手順はこれからも変わります。

## ボタンの名前の書き方

Blender を日本語表示にしていると、このアドオンのボタンも日本語で出ます。この説明書では、**日本語表示の名前**を先に書き、**英語表示の名前**を括弧の中に書きます（例: 「フェーズシム」（Phase Sim））。一部のボタンは、日本語表示でも英語のままです。
