# 用語集

この説明書と画面に出てくる言葉です。画面の表示は、日本語表示のときの名前と、英語表示のときの名前を並べています。

## 型紙と縫い目

| 言葉 | 画面の表示 | 意味 |
|---|---|---|
| 型紙のデータ | — | 服 1 着ぶんの情報（型紙の形、縫い目、置き場所、折り、役割、生地）。Blender のテキスト `AC9_ClothSim_Spec_<服の名前>` に入っています。画面の型紙は、ここから作られる表示です。 |
| 服 | 「**服**」（Garment） | 型紙のデータ 1 つ。1 つのシーンに何着でも入れられ、「服」の欄で切り替えます。 |
| ピース | 「**ピース**」（Pieces） | 型紙の 1 枚。CAD のパーツにあたります。 |
| 外周・角・辺 | — | ピースの輪郭（出来上がり線）と、その角と、角と角の間の線。 |
| 内部線 | 「**内部線**」（Internal Line） | ピースの中の線。折り線、ダーツの脚、ポケットの位置などに使います。閉じた図形にもできます。 |
| 縫い目 | 「**縫い目**」（Seams） | 2 つの区間（A 側と B 側）を縫い合わせる指定。A と B は同じ端から始めます。 |
| 合印 | 「**合印**」（Notches） | 縫い合わせる位置の目印（ノッチ）。 |
| ダーツ | — | 外周から内側へ向かう三角の切り込み。脚どうしを縫い合わせます。 |
| 切り開き | 「**切り開き**」（Slash and Spread） | 内部線でピースを切り開いて広げる操作（フレア、ギャザー）。 |
| 左右ペア | 「**ペア**」（Pair） | 左右対称の 2 枚。片方を直すと、相手も鏡の形で直ります。 |
| 折り | 「**折り**」（Fold） | 内部線で布を折った形にすること。山折り・谷折りと角度を決めます。 |
| ピースの役割 | 「**ピースの役割**」（Piece Roles） | 身頃・衿・袖などの役割。縫う順番に使います。 |

## 置く・着せる

| 言葉 | 画面の表示 | 意味 |
|---|---|---|
| 体 | 「**体**」（Body） | 服を着せるアバターの体のメッシュ。 |
| ガイド | 「**ガイド検出**」（Detect Guides） | 体の胴・首・腕・脚にかぶせる円柱。ピースを置く目安です。 |
| 平らな型紙 | — | 床の上に並んだピース。読み込んだ・描いた直後の形。 |
| 置いた形 | 「**配置**」（Place） | ガイドの上に置いたピース。シミュレーションはこの形から始まります。 |
| 着た服 | 「**AC9 服**」（AC9 Garment）の結果 | 着せた後の服（オブジェクト `AC9_Garment_<服の名前>`）。 |
| シミュレーション | — | 布の動きの物理計算。NVIDIA の Newton で計算します。 |
| 段 | — | 「フェーズシム」の中の 1 区切り。縫い目を閉じる段、重力をかけて垂らす段などを順に進みます。 |
| コマ（フレーム） | — | 経過の 1 枚。タイムラインで再生できます。 |
| 経過（キャッシュ） | 「**キャッシュを削除**」（Delete Cache） | シミュレーションのコマの記録。保存した .blend の隣のフォルダに入ります。 |
| ピースの状態 | 「**アクティブ**」（Active）、「**フリーズ**」（Freeze）、「**型紙から外す**」（Off Pattern）、「**全部オフ**」（Off All） | ピースを動かすか、ほかの布と当たるか、縫い目を使うか。 |
| 障害物 | 「**コリジョン**」（Collision） | 布が当たるけれど動かない物。着せ終わったほかの服は、自動で障害物になります。 |

## 生地

| 言葉 | 画面の表示 | 意味 |
|---|---|---|
| 生地 | 「**生地**」（Fabrics） | 布の硬さ・重さなどの物性。ピースごとに 1 つ選びます。 |
| 芯地 | 「**芯地**」（Interlining） | ピースに貼る芯。そのピースを硬くします。 |
| ゴム | 「**ゴム**」（Elastic） | ピースや内部線を縮める率。 |
| 粒子間隔 | 「**粒子間隔 (mm)**」（Particle Distance (mm)） | 布を細かい三角に分けるときの点の間隔。小さいほど細かく、計算は重くなります。 |

## Blender の言葉

| 言葉 | 意味 |
|---|---|
| オブジェクトモード／編集モード | 物を丸ごと扱うモードと、頂点・辺・面を直すモード。AC9 Cloth Sim はオブジェクトモードで使います。 |
| アクティブ | 最後に選んだ物。Tool タブには、アクティブな物の設定が出ます。 |
| サイドバー | 3D ビューポートの右端のパネル（**N** キー）。 |
| Tool タブ | 画面右下の Properties エディタのタブの 1 つ。実行のボタンと、選んだ物の設定が出ます。 |
| ワークスペース | 画面の並べ方。AC9 Cloth Sim の「**作業画面**」（Work Screen）もその 1 つ。 |
| オーバーレイ | 3D ビューポートに重ねて描く線や印。右上のボタンで切り替えます。 |
