# AC9 Cloth Retopo へ渡す

着せた服から、Cloth Retopo に渡す `AC9_Guide_<服の名前>` を作ります。縫い目はぴったり閉じます。型紙の平らな形はシェイプキー `UVMap_Flattened`（実寸）に入ります。Cloth Retopo が有効なら、その Guide に自動で設定します。

- 前提: 着せた結果があること。
- 操作: 画面に出ているコマを使うので、普通はタイムラインを最後のコマにしてから、「**詳細**」（Details）の中の「**AC9 Cloth Retopo へ渡す**」（To AC9 Cloth Retopo）を押します。
- 期待結果: 画面に頂点数と、縫い目がどれだけ開いていたか（閉じる前）が出ます。同じ名前の Guide があれば作り直します。
