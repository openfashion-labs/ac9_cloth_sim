# 全体の流れ

1. 「**セットアップ**」（Setup）— 型紙を読み込む（「**BOM を新規読み込み**」（Import BOM）、「**DXF を読み込む**」（Import DXF）、または 3D で作ったメッシュから「**メッシュから**」（From Mesh））。
2. 「**型紙**」（Pattern）— 必要なら型紙を直す、新しく描く。
3. 「**縫い目**」（Seams）— 縫い目が正しいか確かめる、足す、直す。
4. 「**配置**」（Placement）— 体を選び、「**ガイド検出**」（Detect Guides）で置く目安を作り、型紙を体のまわりに「**配置**」（Place）で置く。
5. 「**AC9 実行**」（AC9 Run）（Tool タブ）—「**ライブシム**」（Live Sim）で縫って着せる。気に入らない所は「**置いた形に戻す**」（Back to Placed）、「**手で直す**」（Fix by Hand）、「**ライブシム**」（Live Sim）などで直して続ける。
6. 「**AC9 Cloth Retopo へ渡す**」（To AC9 Cloth Retopo）— Cloth Retopo へ渡す。
7. 「**採寸**」（Measure）— 採寸とサイズの確認（いつでも）。
