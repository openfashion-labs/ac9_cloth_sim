# 折り

## 内部線の折り

内部線や縫い目に折りの角度を付けます。調整した形を折ることと、シミュレートで折り目を保つことは別です。型紙の上で内部線をクリックすると選ばれ（オレンジ色）、Tool タブに「**AC9 内部線**」（AC9 Internal Line）が出ます。

- 「**折りの角度**」（Fold Angle）: 折る角度（0〜180°、0 で折らない）。角度が 0 でないときは、その下に次の欄が出ます。
  - 「**方向**」（Direction）:「**山折り**」（Mountain）（山折り）か「**谷折り**」（Valley）（谷折り）。布の表から見た向きです。3D でピースを裏返すと、折りも布と一緒に裏返ります。
  - 「**倒す側**」（Turns）:「**指定なし**」（No Side）／「**A側**」（Side A）／「**B側**」（Side B）。指定なしでは山谷と角度だけを設定し、配置時に片側全体を倒しません。蛇腹やタックなどに使います。A側・B側は、調整した形で倒す側です。線の両脇に A（オレンジ、描き始めから見て左）・B（青）の札が出ます。鏡のペア（「**ミラーコピー**」（Mirror Copy）の対、「**対称編集**」（Symmetric Edit）のピースの左右の線、BOM の左右の対）では、相方の線の A は元の線の A の鏡の側です（相方では線の右に来ることがあります）。折りの設定は相方へ同じ文字のまま写ります。以前のファイルで相方と A・B の名前が逆になっている線を選ぶと「鏡の相方と A / B の名前が逆」と出ます。「**鏡の A/B をそろえる**」（Match Mirror A/B）で名前だけをそろえます（倒れる側・残す層の場所は変わりません）。角度を打ち直しても同じようにそろいますが、そのとき相方の折りは打ち直した線と同じ設定になります（相方だけ別に直していた値は上書きされます）。実行中に変更できる条件は下の表で確認します。
  - 「**計算する層**」（Layers）は試験中です。アドオンの設定の「**試験中の機能**」（Experimental Features）をオンにしたときだけ表示します。「**両方**」（Both）（2 層で計算、既定）、「**Aのみ**」（A only）／「**Bのみ**」（B only）（その側だけを計算し、反対側は 2 層目として付いていく。折って縫い閉じた前立てなど）。非表示にしても、以前保存した設定は変更しません。
- 倒す側を A側・B側にして欄を変えると、調整した形がその場で折れます（角度 0 で平らに戻る）。この形で置いて縫います。
- 調整した形で折れない線は、理由が 1 行出ます。ピースの中で止まる線（タックなど）は、シミュレーションでは折れますが A・B はありません。
- 左右ペアの相方の線にも同じ折りが入ります。縫い目が沿っている内部線も折れます。
- 左右のミラーペアでは、内部線の追加・移動・曲線編集・削除も相方へ反映されます。相手の線は追加した時点で2D型紙に表示され、同じ操作でUndoできます。配置の「連動解除」だけでは型紙の同期は解除されません。
- 古いデータで相方の線が欠けている場合、配置や計算の準備中に線を自動追加しません。形の生成時には内部線と設定が一致するペアだけを共有します。古い共有形で線の対応を確認できない場合は、A/B操作を理由付きで拒否します。
- 床に置いたピースでも A側・B側を使えます。山折り・谷折りは床の向きではなく布の表を基準にします。中央軸で対称編集する1枚では、軸上の折り線は1回だけ、軸から離れた鏡像2線はそれぞれ1回ずつ折ります。どちらの線から選んでも同じ順序で折り、指定なしで両方を戻します。
- 角度を入れた線は、シミュレーションの全部の段で、アイロンを当てた折り目として扱われます（布の曲げの 10 倍の硬さで角度を保つ）。
- 「**ゴム**」（Elastic）: 線に沿って縮める率（100 % で縮めない）。その下に、線に縫ってある縫い目と、周りまでの距離と「**数値入力…**」（Numeric Input...）。2 枚に切る「**線で切る**」（Cut Along Line）と削除（X）は右クリックのメニューにあります。

新しく角度を入れる線は「指定なし」で始まります。以前のファイルの折りは倒す側を保ちます（古い記録で側が省略されている場合は従来どおり A側）。「指定なし」でも計算する層は別に選べます。

A側・B側から指定なしへ切り替えると、保存してある折る前の配置形に戻ります。後から入れた折り、頂点ごとの手編集、折る前の保存形の欠損によって安全に戻せない場合は、設定と形を保って理由を表示します。

## 縫い目をまたぐ折り

「縫い目編集」で縫い目を選び、Tool タブの「AC9 縫い目」で角度・方向・倒す側を設定します。内部線は1枚の中を折り、縫い目はつながる2枚の間を折ります。設定欄の場所は「[縫い目](seams.md)」を見てください。

## 設定はいつ効くか {#when-settings-apply}

| 設定 | 調整した形 | シミュレート開始時 | シミュレート中の変更 |
|---|---|---|---|
| 内部線の角度・方向 | 倒す側がA側/B側のときに折る | 折り目として使う | 開始時に角度が0°でなかった線だけ変更できる |
| 内部線の倒す側 | 倒す側を変える。指定なしは片側を倒さない | 計算の折り方は決めない | 変更できない |
| 内部線の終端減衰（Taper） | 変わらない | ピース内で止まる端だけなだらかにする | 開始時と現在の角度が0°でなく、ピース内で止まる端がある線だけ変更できる |
| 縫い目の角度・方向 | 倒す側のピースを回す | 2枚の間の折り目として使う | 開始時に角度が0°でなかった縫い目だけ変更できる |
| 縫い目の倒す側 | 回すピースを選ぶ | 開始時の設定を使う | 変更できない。停止して設定し、再実行する |

**開始時に0°だった線・縫い目を新しく折るときは、停止して角度を設定し、もう一度シミュレートします。** 実行中は該当欄がグレーになり、理由が表示されます。内部線の「指定なし」でも、開始前に角度を入れていれば計算中の折り目になります。調整した形が折れていないだけで、設定が無効とは限りません。

**終端減衰は角度ではなく長さです。** ピース内で止まる端から、どれだけの範囲をなだらかにするかを指定します。外周に達した端には効きません。両端が外周なら欄は出ず、現在の角度が0°なら欄は操作できません。画面の単位を確認してください。線の長さに比べて大きい値では、線全体の折りが弱くなります。

内部線の「計算する層」（試験中）は開始時に決まり、実行中には変更できません。通常の折り角度や倒す側とは別の設定です。
