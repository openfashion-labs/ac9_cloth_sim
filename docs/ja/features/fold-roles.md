# ピースの役割と折り

## ピースの役割（Piece Roles）

役割によって、何番目の段で縫うかが決まります（身頃、衿、袖、付属品の順）。役割が間違っていると、縫う順番がおかしくなって崩れることがあります。縫う順番のほかに、置き方や始まりの形も役割で決まります。くわしくは「[ピースの役割と自動で決まること](roles.md)」を見てください。

- 上の行に、服の種類、役割が決まったピースの数、確かめてほしい数が出ます。
- 「**役割を提案**」（Propose Roles）: 型紙の形と、元データの手がかり（配置点、ピース名、生地名など）から、全ピースの役割を提案します。自分で決めた役割は上書きしません。自信の低いものには警告が付きます。
- 役割を自分で決めるには、ピースを選び、Tool タブの「**AC9 ピース**」（AC9 Piece）の「**役割**」（Role）を押して一覧から選びます（左右ペアの相方も同じになります）。
- 一覧は、ピースごとの役割です。警告は確かめてほしい、人の印は自分で決めた、を表します。

## 折り（Fold）

内部線で布を折った形にして置く機能です（衿を折り返す、など）。型紙の上で内部線をクリックすると選ばれ（オレンジ色）、Tool タブに「**AC9 内部線**」（AC9 Internal Line）が出ます。

- 「**折りの角度**」（Fold Angle）: 折る角度（0〜180°、0 で折らない）。角度が 0 でないときは、その下に次の欄が出ます。
  - 「**方向**」（Direction）:「**山折り**」（Mountain）（山折り）か「**谷折り**」（Valley）（谷折り）。布の表から見た向きです。3D でピースを裏返すと、折りも布と一緒に裏返ります。
  - 「**倒す側**」（Turns）:「**指定なし**」（No Side）／「**A側**」（Side A）／「**B側**」（Side B）。指定なしでは山谷と角度だけを設定し、配置時に片側全体を倒しません。蛇腹やタックなどに使います。A側・B側は、置いた形で倒す側です。線の両脇に A（オレンジ、描き始めから見て左）・B（青）の札が出ます。変わるのは置いた形だけです。
  - 「**計算する層**」（Layers）:「**両方**」（Both）（2 層で計算、既定）、「**Aのみ**」（A only）／「**Bのみ**」（B only）（その側だけを計算し、反対側は 2 層目として付いていく。折って縫い閉じた前立てなど）。自動では切り替わりません。
- 倒す側を A側・B側にして欄を変えると、置いた形がその場で折れます（角度 0 で平らに戻る）。この形で置いて縫います。
- 置いた形で折れない線は、理由が 1 行出ます（試験中の機能をオンにしていると「**ローカルシム**」（Local Sim）のボタンも出ます）。ピースの中で止まる線（タックなど）は、シミュレーションでは折れますが A・B はありません。
- 左右ペアの相方の線にも同じ折りが入ります。縫い目が沿っている内部線も折れます。
- 角度を入れた線は、シミュレーションの全部の段で、アイロンを当てた折り目として扱われます（布の曲げの 10 倍の硬さで角度を保つ）。
- 「**ゴム**」（Elastic）: 線に沿って縮める率（100 % で縮めない）。その下に、線に縫ってある縫い目と、周りまでの距離と「**数値で動かす…**」（Move by Number...）。2 枚に切る「**線で切る**」（Cut Along Line）と削除（X）は右クリックのメニューにあります。

新しく角度を入れる線は「指定なし」で始まります。以前のファイルの折りは倒す側を保ちます（古い記録で側が省略されている場合は従来どおり A側）。「指定なし」でも計算する層は別に選べます。

A側・B側から指定なしへ切り替えると、保存してある折る前の配置形に戻ります。後から入れた折り、頂点ごとの手編集、折る前の保存形の欠損によって安全に戻せない場合は、設定と形を保って理由を表示します。
