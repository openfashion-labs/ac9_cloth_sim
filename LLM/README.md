# AC9 Cloth Sim 使い方（AI 向けの写し）

この文書は `docs/ja/` の章から `docs_to_llm.py` で作った写しです。直すときは `docs/ja/` の章を直してください。
ボタンごとの操作と操作 ID は `procedures.md` にあります。

## Blender の基本

AC9 Cloth Sim を使うのに必要な、Blender の見方と操作だけをまとめます。Blender 全体については、[Blender の公式マニュアル](https://docs.blender.org/manual/ja/latest/)などを見てください。

Blender のメニューやボタンは、日本語表示では日本語で出ます。この章では、Blender 自体のメニュー名を英語で書き、分かるものは日本語を添えます。

### 作業画面にたどり着くまで

#### 1. 開いた直後の画面

Blender を起動して .blend を開くと、ふつうは「Layout」の画面になります。大きな **3D ビューポート**（体や服を立体で見る所）、右上に Outliner（シーンの物の一覧）、右下に Properties エディタ（設定の窓）、下にタイムライン（コマの帯）が並びます。

画面のいちばん上に並んでいるタブ（Layout、Modeling など）は「ワークスペース」で、画面の並べ方を切り替えます。

#### 2. サイドバーを出して、AC9 Cloth Sim のタブを開く

1. マウスを 3D ビューポートの上に置き、**N** キーを押します。3D ビューポートの右端に **サイドバー** が出ます（もう一度 **N** で引っ込みます）。
2. サイドバーの右の端に、縦書きのタブ（アイテム、ツール、ビューなど）が並びます。その中の **「AC9 Cloth Sim」** を押します。
3. 「**セットアップ**」（Setup）・「型紙」・「リスト」・「配置」・「採寸」などのパネルが並びます。**見出しの ▸ を押すと、そのパネルが開きます。**

タブが無いときは、アドオンがオンになっているか（インストール）、マウスを 3D ビューポートの上に置いて **N** を押したかを確かめます。

#### 3. 作業画面に切り替える

「**セットアップ**」（Setup）のパネルの「**作業画面**」（Work Screen）を押します。AC9 Cloth Sim 用のワークスペースができて、画面が次の並びに変わります。**この後の説明は、すべてこの作業画面で行います。** 元の画面に戻るときは、いちばん上のタブの「Layout」を押します。

| 番号 | 場所 | 何をする所か |
|---|---|---|
| 1 | **3D ビューポート**（左） | 体と服を立体で見る所。体のまわりにピースを置くのもここ |
| 2 | **型紙のビュー**（真ん中） | 真上から見た平らな型紙。**回転はできません** |
| 3 | **道具の列**（型紙のビューの左端。**T** で出し入れ） | 型紙を直す・縫い目を付ける・置く、などの「道具」を持ち替えます |
| 4 | **サイドバー**（型紙のビューの右端。**N** で出し入れ） | 「AC9 Cloth Sim」のタブ。読み込み・型紙・一覧・配置・採寸のパネル |
| 5 | **Properties エディタの Tool タブ**（右。ドライバーとレンチの形のタブ） | **実行のボタン**（「AC9 実行」（AC9 Run））と、選んだ物の設定 |

- **実行のボタン（「ライブシム」など）はサイドバーではなく、Tool タブにあります。** Properties エディタが別のタブ（Render や Object など）になっていると見つかりません。
- 作業画面には Outliner がありません。いちばん下にタイムラインがあります（「コマとタイムライン」）。

### 視点を動かす

| 操作 | マウス・キー |
|---|---|
| 回す | 中ボタン（ホイール）を押したままドラッグ |
| 平行に動かす | **Shift**＋中ボタンでドラッグ |
| 近づく・離れる | ホイールを回す |
| 正面・横・上から見る | テンキーの **1**／**3**／**7** |
| 選んだ物に寄る | テンキーの **.**（ピリオド） |
| 全体を見る | **Home** |
| いまのビューを画面いっぱいにする／戻す | **Ctrl＋Space** |

- 作業画面の真ん中の型紙のビューは回りません。回るのは左の 3D ビューポートだけです。
- 3D ビューポートの右上にある、色の付いた軸の丸（ナビゲーションギズモ）をドラッグしても回せます。軸の丸をクリックすると、その向きから見ます。

#### 中ボタンやテンキーが無いとき（ノートパソコンなど）

「Edit」→「Preferences」（編集 → プリファレンス）の「Input」（入力）で、次の 2 つをオンにします。

- **Emulate 3 Button Mouse**: **Alt**＋左ドラッグが、中ボタンのドラッグの代わりになります。
- **Emulate Numpad**: キーボードの上の段の数字キーが、テンキーの代わりになります。

### 選ぶ

| 操作 | マウス・キー |
|---|---|
| 選ぶ | 左クリック |
| 足す・外す | **Shift**＋左クリック |
| 全部を選ぶ | **A** |
| 選択を外す | **Alt＋A** |

- 最後に選んだ物は「アクティブ」と呼ばれ、ほかの選んだ物より明るい色で表示されます。**Tool タブには、アクティブな物の設定が出ます。** 思った設定が出ないときは、何がアクティブかを確かめます。
- 押せない（灰色の）ボタンは、カーソルを置くと、押せない理由が出ます。

### 動かす・取り消す

| 操作 | キー |
|---|---|
| 動かす／回す／拡大縮小 | **G**／**R**／**S**。続けて **X**・**Y**・**Z** で軸を決め、数字で値を入れます |
| 確定する | 左クリックか **Enter** |
| 取り消す（操作の途中） | 右クリックか **Esc** |
| 元に戻す／やり直す | **Ctrl＋Z**／**Ctrl＋Shift＋Z** |
| 直前の操作の値を変える | **F9**（または画面の左下に出る小さなパネル） |
| 消す | **X** か 「**削除**」（Delete） |
| 名前から操作を探して実行 | **F3** |

**型紙のピースは、Blender の G／R／S では動きません。** ピースには鍵が掛かっています。ピースを丸ごと動かすのは「**ピース全体**」（Whole Pieces）、角や辺を直すのは「**ピース編集**」（Edit Pieces）の道具です。

右クリックには 2 つの意味があります。操作の途中なら取り消し、何もしていないときは、カーソルの下の物に使えるメニューが出ます（AC9 の道具を持っているとき）。

### オブジェクトモードと編集モード

Blender には「モード」があります。3D ビューポートの左上で切り替え、**Tab** キーでも行き来できます。

- **オブジェクトモード**: 物（オブジェクト）を丸ごと扱うモード。**AC9 Cloth Sim の操作は、このモードで行います。**
- **編集モード**: 1 つの物の頂点・辺・面を直接直すモード。

注意:

- **型紙を編集モードで直しても、型紙のデータには入りません。** 型紙は、型紙のデータ（服 1 着ぶんの情報）から作り直される表示です。直すのは AC9 の道具で行います。
- AC9 の道具はオブジェクトモードの道具の列にだけあります。**編集モードに入ると、AC9 の道具が見えなくなります。** 道具が消えたら、**Tab** でオブジェクトモードに戻ります。
- 編集モードを使うのは、着た服の形を手で直すとき（「**手で直す**」（Fix by Hand）の後）だけです。

### 隠す・見せる

- **H** で選んだ物を隠し、**Alt＋H** で全部を見せます。隠した物は消えたわけではありません。
- 型紙のピースを使わないときは、**H** で隠すのではなく、ピースの状態を「オフ」にします（考え方の「ピースの 4 つの状態」）。
- 3D ビューポートの右上の、重なった 2 つの丸のボタン（オーバーレイ）を切ると、AC9 Cloth Sim が画面に描く線や色も見えなくなります。

### コマとタイムライン

シミュレーションの経過は、コマ（フレーム）ごとのアニメーションとして残ります。

- **Space** で再生・停止します。
- **←**／**→** で 1 コマずつ、**Shift＋←**／**Shift＋→** で最初と最後のコマへ動きます。
- **画面に出ているコマが意味を持つ操作があります。** 2 回目以降の「ライブシム」（Live Sim）は、画面に出ているコマから続けます。Cloth Retopo へ渡すときや、服を採寸するときも、画面に出ているコマを使います。押す前に、最後のコマになっているかを確かめます。
- タイムライン（コマの帯）を出したいときは、エリアの左上のエディタの種類のメニューから「Timeline」を選びます。

### ファイルの保存

- **Ctrl＋S** で保存します。初めて保存するときは、保存先と名前を聞かれます。
- **シミュレーションの前に、一度保存してください。** 経過のコマは、保存した .blend の隣の `AC9_ClothSim_jobs` フォルダに作られます。保存していないと一時フォルダに作られ、あとで再生できなくなります。
- 着せた服の最後の形は、.blend の中に保存されます。.blend だけを別のパソコンに渡しても、最後の形は見えて、そこから続けられます（経過の再生だけはできません）。
- 保存した後に .blend を移動したり名前を変えたりすると、経過のフォルダが見つからなくなります（最後の形は残ります）。

### ファイルを選ぶ画面

「BOM を新規読み込み」などを押すと、Blender のファイルを選ぶ窓が開きます。

- 窓の上の欄にフォルダの場所が出ます。ここにフォルダのパスを貼り付けて **Enter** を押すと、そのフォルダへ移れます。左の列の「ドライブ」やよく使う場所からたどることもできます。
- フォルダはダブルクリックで中に入ります。上の欄の左の ↑（親のフォルダ）で戻ります。
- 選べるファイルだけが表示されます（BOM なら .xml）。ファイルを 1 回クリックして、右下の青いボタン（「BOM を新規読み込み」など、押したボタンと同じ名前）を押します。ファイルをダブルクリックしても同じです。
- やめるときは「キャンセル」か **Esc**。

### アドオンの入れ方と言語

- アドオンの入れ方は、[README](https://github.com/openfashion-labs/ac9_cloth_sim#インストール) の「インストール」を見てください。新しい版を入れたら、Blender を起動し直します。
- 日本語で使うときは、「Edit」→「Preferences」の「Interface」で「Translation」を日本語にします。サイドバーのタブ名「AC9 Cloth Sim」と、一部の文字やエラーの文は英語のままです。

### つまずきやすいこと

- **日本語入力（IME）がオンだと、キーボードのショートカットが効きません。** キーが効かないときは、まず日本語入力をオフにします。
- キーは、カーソルが乗っているエリアに効きます。3D ビューポートの操作は、カーソルを 3D ビューポートの上に置いてから行います。
- 何かを押したら画面が変わって戻せない、と思ったら、まず **Ctrl＋Z** を試します。

## はじめての 1 着

何も無い状態から、T シャツの型紙を自分で描いて、付属のアバターに着せるまでを通します。
ボタンの名前は「日本語表示の名前」（英語表示の名前）の順に書いています。Blender の操作に慣れていない方は、先に Blender の基本 を読んでください。

<!-- video: はじめての 1 着（章ごとに 1〜2 分） -->

作る型紙は 6 枚です。

| ピース | 作り方 |
|---|---|
| 前身頃 | 長方形を描いて、角を動かして形にする |
| 後ろ身頃 | 前身頃を複製して、衿ぐりを直す |
| 袖（左右） | 片方を描いて、ミラーコピーで左右ペアにする |
| 衿ぐりのリブ（左右） | 細い長方形を描いて、ミラーコピー |

### 用意するもの

- AC9 Cloth Sim を入れた Blender 5.2（入れ方は「インストール」）。体も型紙も要りません。体は付属のアバター（CC0）を使います。

自分の体（アバター）や、ほかのソフトで作った型紙（`BOM.xml`・DXF・SVG・服のメッシュ）から始めるときは、最後の「ほかの始め方」を見てください。

### 1. 作業画面に入る

1. Blender を起動して、新しいファイルのまま、**最初に別の名前で保存します**（**Ctrl＋Shift＋S**）。シミュレーションの経過は、保存した .blend の隣にできるフォルダに残ります。
2. 3D ビューポートで **N** を押してサイドバーを出し、「AC9 Cloth Sim」のタブを開きます（Blender の基本の「作業画面にたどり着くまで」）。
3. 「**セットアップ**」（Setup）のパネルの「**作業画面**」（Work Screen）を押します。左に 3D、真ん中に型紙、右に Tool タブが並んだ画面になります。

### 2. アバターを読み込んで、採寸する

1. 「**セットアップ**」（Setup）の「**アバターを追加**」（Add Avatar）を押します。左の 3D にアバターが入り、「**体**」（Body）の欄にも設定されます。
2. サイドバーの「**採寸**」（Measure）のパネルで「**体を採寸**」（Measure Body）を押します。バスト・ウエスト・ヒップ・首・腕などの寸法が表に出て、測った場所が体のまわりに線で描かれます。

この寸法を、これから描く型紙の大きさの目安にします。たとえば前身頃の幅は「バストの 1/4＋ゆとり」くらいです。長さの単位は「**セットアップ**」（Setup）の「**単位**」（Units）で変えられます。

### 3. 前身頃を長方形から作る

1. 「**セットアップ**」（Setup）の「**新しい服**」（New Garment）を押します。ピースが 1 枚も無い服ができます。
2. 「**型紙**」（Pattern）のパネルの「**ピース**」（Piece）の「**長方形**」（Rectangle）を押し、真ん中の型紙のビューでドラッグして長方形を描きます。大きさを数字で決めるときは、描き始めてから幅を打って **Tab**、高さを打って **Enter** です。
3. 「**ピース編集**」（Edit Pieces）を押して、角をドラッグして形にします。
   - 辺の上で **K** を押すと、そこに点が足せます（肩先・脇の下の点など）。
   - 辺の上で **C** を押すと、その辺がカーブになります。取っ手をドラッグして、衿ぐりと袖ぐりを丸くします。
   - 動かしている間は、長さと周りまでの距離が mm で出ます。数字を打つと、その長さで止まります。
4. 名前を付けます。ピースを選んで **F2** か、Tool タブの「**AC9 ピース**」（AC9 Piece）のいちばん上の欄に「Front」などと入れます。

左右対称のピースは、Tool タブの「**対称編集**」（Symmetric Edit）をオンにすると、片側の角を動かすだけで反対側も鏡で動きます（詳しくは「型紙を直す・描く」）。

### 4. 後ろ身頃を複製で作る

1. 前身頃を選んで、「**選んだピース**」（Selected Pieces）の「**複製**」（Duplicate）を押します（**Shift＋D** でも同じ）。写しはマウスに付いてくるので、前身頃の横でクリックして置きます。
2. 「**ピース編集**」（Edit Pieces）で、衿ぐりを浅く直します（後ろの衿ぐりは前より浅い）。
3. 名前を「Back」にします。

### 5. 袖を左右ペアで作る

1. 「**ピース**」（Piece）の「**描く**」（Draw）を押し、角を順にクリックして片方の袖を描きます。最初の角をもう一度クリック（か **Enter**）で閉じます。
2. 「**ピース編集**」（Edit Pieces）で、袖山の辺を **C** でカーブにして丸くします。
3. 袖を選んで、「**選んだピース**」（Selected Pieces）の「**ミラーコピー**」（Mirror Copy）を押します。鏡写しのもう片方ができ、2 枚が左右ペアになります。ペアは、片方を直すともう片方も鏡で直ります。
4. 衿ぐりのリブも同じように作ります。細い長方形（長さは衿ぐり 1 周の半分くらい、幅は 1〜2 cm）を描き、「**ミラーコピー**」（Mirror Copy）で左右の 2 枚にします。1 枚が、前中心から後ろ中心までの衿ぐりの片側を受け持ちます。

### 6. 縫い目を付ける

1. 「**型紙**」（Pattern）のパネルの「**縫い目を追加**」（Add Seam）を押します。
2. 片方のピースの外周で始点と終点、相手のピースで始点と終点の順にクリックします（**両方とも同じ端から**）。辺の途中をクリックすると、その辺を丸ごと取ります。4 点で両側の長さと差が出るので、見直して **Enter** で足します。区間が逆回りに取られたときは **F** で向きを逆にします。
3. 次の所を縫います。
   - 前身頃と後ろ身頃の、肩と脇
   - 袖の袖下（袖を筒にする）
   - 袖と身頃の袖ぐり（袖付け）
   - リブと衿ぐり（前・後ろ）、左右のリブどうし（前中心と後ろ中心）
4. 袖下のように、左右ペアのピースどうしの縫い目は、片側を縫うと反対側にも鏡で入ります。身頃のように 1 枚のピースとの縫い目は、左右とも縫います。

縫い目は、サイドバーの「**リスト**」（Lists）の「**縫い目**」（Seams）タブに 1 行 1 本で並びます。両側（A と B）の長さと、差があれば差（mm）が出ます。

縫い目の付け方の詳しい説明は「縫い目」にあります。

### 7. 置く目安を作る

1. サイドバーの「**配置**」（Placement）のパネルで、「**体**」（Body）の欄にアバターが入っていることを確かめます。
2. 「**ガイド検出**」（Detect Guides）を押します。胴・首・腕・脚のまわりに、ピースを置く目安の円柱（ガイド）ができます。円柱がずれていたら、「**ガイドを編集**」（Edit Guides）で直せます。

### 8. ピースを体のまわりに置く

1. 「配置」（Placement）のパネルの「**配置**」（Place）を押して、道具を持ちます。
2. 型紙のビューでピースをクリックして選びます（**Shift** で足す）。左右のペアは、片方を置くと相手も鏡の位置に付いてきます。
3. 左の 3D ビューポートで、置きたい円柱の上にカーソルを持っていきます（円柱が黄色に光ります）。
4. 円柱の上で押すと、そこに置かれます。**押したまま動かす**と、円柱のまわり・円柱に沿って滑ります。離した所で決まります（置いたピースを押してドラッグすると、跳ばずに動かした分だけ動きます。角度だけ・高さだけ変えるときと、ピースを倒すときは、Tool タブ「AC9 Piece」の Around（まわりの角度）・Height（高さ）・Tilt（倒す角度。90° で上側が外へ水平、180° で上下逆＝衿の外周が首の側。横の ↻ で +180°））。
5. すべてのピースを置くまで繰り返します。パネルに「○ / ○ pieces placed」（置いた数／使う数）が出ます。

どのピースをどの円柱に置くかの目安:

| ピース | 置く円柱 | 置く所 |
|---|---|---|
| 前身頃 | 胴 | 体の前（正面） |
| 後身頃 | 胴 | 体の後ろ |
| 袖 | 腕 | 左右の腕に 1 枚ずつ。袖山を肩の側に |
| 衿・衿ぐりのリブ | 首 | 首のまわり |
| スカート・パンツ | 胴・脚 | 腰から下 |

- 後ろ側に置くときは、左の 3D ビューポートで視点を回して、体の後ろが見えるようにしてから置きます（中ボタンのドラッグ。中ボタンが無いときは Blender の基本の「中ボタンやテンキーが無いとき」）。
- 前と後ろ、左と右を取り違えても、計算はそのまま進みます。おかしな着方になったら、置き直します。

離したときに見えている形が、シミュレーションが始まる形です。赤くなったピースは、体に入っている・ほかのピースと重なっているピースです（理由が出ます）。そのままでも始められますが、置き直すか、「配置」パネルの整える道具を使うときれいに始まります。

置き直したいときは、ピースを選んでもう一度「**配置**」（Place）で置きます。「**平面に戻す**」（Back to Flat）は、その場で平らにします。

### 9. 着せる（ライブシム）

1. 右の Tool タブのいちばん上（「**AC9 実行**」（AC9 Run））の「**ライブシム**」（Live Sim）を押します。
2. はじめは計算の準備で、少し待ちます（3D ビューに「シミュレーションを準備中（経過 N 秒）」と出ます。はじめて着せるときは、もう少しかかります）。**この間は布が動きませんが、止まってはいません。ボタンをもう一度押さずに待ちます**（もう一度押すと止まります）。
3. 計算が始まると、縫い目が引き寄せられて閉じ、服が体に落ち着いていきます。
4. **自動では止まりません。** 服が落ち着いて動かなくなったら、ボタン（「**停止**」（Stop）に変わっています）をもう一度押すか **Esc** を押します。止めた所の形が結果です。

- 衿や袖が、縫い付く前に落ちてしまうときは、「**重力**」（Gravity）のチェックを外して回し、縫い目が閉じてからチェックを入れます（回っている間に切り替えられます）。
- 計算にかかる時間は、服の大きさとパソコンによって変わります。

### 10. 結果を見る

- 何も選んでいない状態で Tool タブを見ると、「**AC9 服**」（AC9 Garment） に結果（Result）が出ます。
- 赤い塗りは「異常の候補」です。そのまま不良という意味ではありません。
- 同じ設定でも、計算のたびに仕上がりが少し変わります。1 回で良し悪しを決めず、何度か回して見てください。
- うまく着られたかの目安: 袖が腕に付いている、衿（衿ぐり）が首を囲んでいる、布が体の中に入り込んでいない。

**2 回目からは、今の服の形から続けて計算します。**

### 11. 直して、もう一度着せる

- **型紙を直す**: 「**型紙**」（Pattern） パネルの「**ピース編集**」（Edit Pieces）で角や辺をドラッグします。着た服は、すぐには変わりません。続けて「**ライブシム**」（Live Sim）を押すと、直した形を着た服に写してから**今の形から続けて**計算し、直した型紙に落ち着きます。直すたびに 3D の形を見たいときは、Tool タブの「**AC9 実行**」（AC9 Run）の「**編集を 3D に写す**」（3D Follows Edits）を押します。
- **布を手でつまんで直す**: 「**ライブシム**」（Live Sim）で布が動いている間、**Ctrl＋左ドラッグ**で布をつまんで引っぱれます。布が布を突き抜けたときは、ドラッグ中に **Alt** を押すと、つかんだ布がほかの布をすり抜けます。**Esc** で止めた所の形が残ります。
- **最初から着せ直す**: 何も選ばずに「配置」パネルの「**置いた形に戻す**」（Back to Placed）を押し（確認が出ます）、「**ライブシム**」（Live Sim）を押します。

### 12. 保存する

**Ctrl＋S** で保存します。着せた服の最後の形は .blend の中に、経過のコマは .blend の隣のフォルダに保存されます。

### 次にすること

- 重ね着: 「服」（Garment）の欄でほかの服に切り替えて「ライブシム」を押すと、着せ終わった服は動かない障害物になります。内側の服から順に着せます。
- 生地を変える: ピースを選ぶと、Tool タブの 「**AC9 ピース**」（AC9 Piece） で生地を選べます。
- Cloth Retopo に渡す: Tool タブの 「**AC9 実行**」（AC9 Run） の Details にある「**AC9 Cloth Retopo へ渡す**」（To AC9 Cloth Retopo）で、着せた服を [AC9 Cloth Retopo](https://github.com/openfashion-labs/ac9_cloth_retopo) の Guide にします。

### ほかの始め方

- 自分の体（アバター）を使う: 体の入った .blend を開いて保存し、「**配置**」（Placement）の「**体**」（Body）に体のメッシュを選びます。体はまっすぐ立って、正面が **−Y** を向いているもの（A ポーズでも T ポーズでもかまいません）。
- ほかのソフトの型紙から: 「**BOM を新規読み込み**」（Import BOM）、「**DXF を読み込む**」（Import DXF）、「**SVG を読み込む**」（Import SVG）、「**メッシュから**」（From Mesh）。どれも「セットアップ」に書いてあります。BOM 以外は縫い目が入っていないので、この章の「6. 縫い目を付ける」と同じように付けます。

うまくいかないときは、README の「うまくいかないとき」と、機能ごとの説明の「困ったとき」を見てください。

## 考え方

AC9 Cloth Sim で迷いやすいのは、ボタンの場所よりも「今どの形を見ていて、何を直しているのか」です。この章では、その考え方をまとめます。

### 型紙のデータが正（画面の型紙は表示）

服 1 着ぶんの情報（型紙の形、縫い目、置き場所、折り線、ピースの役割、生地）は、1 つの「型紙のデータ」にまとまっています（Blender のテキスト `AC9_ClothSim_Spec_<服の名前>`、中身は JSON）。

- 画面に並んでいる平らな型紙は、このデータから作り直される**表示**です。
- そのため、**型紙は Blender の普通の編集（編集モード、G/R/S）では直せません。** 直すときは AC9 の道具を使います。
  - ピースを丸ごと動かす・回す: 「**ピース全体**」（Whole Pieces）
  - 角・辺・内部線の点を直す: 「**ピース編集**」（Edit Pieces）
- 型紙を読み込む（Import BOM、Import DXF、From Mesh）たびに、型紙のデータが 1 つ（＝服が 1 着）増えます。パネルの表示は、「**服**」（Garment）の欄で選んでいる 1 着のものです。

<!-- figure: 図2 型紙データと、シーンにできるもの -->

#### シーンにできるもの

| 名前 | 何か |
|---|---|
| コレクション `AC9_ClothSim_Pattern` | 平らな型紙。ピース 1 枚が 1 オブジェクト（`AC9_Piece_<ピース名>`） |
| `AC9_Garment_<服の名前>` | 着た状態の服。最後の形は、このオブジェクトの形そのもの |
| `AC9_Guide_<服の名前>` | Cloth Retopo に渡す服（「AC9 Cloth Retopo へ渡す」で作る） |
| テキスト `AC9_ClothSim_Log` | シミュレーションのログ |

### ピースの 3 つの形と、「戻す」3 つ

1 枚のピースには、3 つの形があります。

<!-- screenshot: ピースの 3 つの形（平らな型紙・置いた形・着た形） -->

| 形 | どこにあるか | 何をした後か |
|---|---|---|
| **平らな型紙** | 床の上（作業画面の真ん中のビュー） | 読み込んだ・描いた直後 |
| **置いた形** | 体のまわりの円柱（ガイド）の上 | 「配置」（Place）で置いた後。シミュレーションはこの形から始まる |
| **着た服** | 体の上 | 「ライブシム」などで着せた後 |

前の形に戻すボタンは 3 つあり、どこまで戻すかが違います（「配置」（Placement）のパネルに、近い順に並んでいます）。

| ボタン | 戻る先 | 捨てるもの |
|---|---|---|
| 「**置いた形に戻す**」（Back to Placed） | 着た服・縫い目へ寄せた形 → 寄せる前の準備形 | 着せた結果と縫い目へ寄せた影響。手配置・頂点編集・折りは残す |
| 「**ガイドに戻す**」（Back to Guide） | → ガイドの上の置き方 | 着せた結果と、手で動かした分 |
| 「**平面に戻す**」（Back to Flat） | → その場で平らに | 対象ピースの手編集と曲がった形（位置と向きは残す）。型紙と縫い目は残す |

ピースを選んで押すとそのピースだけ、何も選ばずに押すと服全体が戻ります（服全体のときは確認が出ます）。
連動中の鏡像は一緒に戻ります。「平面に戻す」でも、未選択のピースの着装形は残ります。

<!-- figure: 図3 ピースの 3 つの姿と「戻す」3 つ -->

型紙を直しても、既定では置いた形と着た服はすぐには変わりません（直すたびに待たないためです）。次に「ライブシム」などを押したとき、直した形を**まとめて置いた形と着た服に写してから**計算し、落ち着かせます（写すときは物理の計算をしません）。直すたびに 3D の形を見たいときは、Tool タブの 「**AC9 実行**」（AC9 Run） の 「**編集を 3D に写す**」（3D Follows Edits） を押します（直すたびに少し待ちます）。「**3D を更新**」（Update 3D） でまとめて写すこともできます。

### 服とピース

- 1 つのシーンに何着でも入れられます。「服」（Garment）の欄で 1 着ずつ切り替えます。
- 1 つの BOM に何着ぶんも入っているときは、読み込むときに服ごとのまとまりに分けられます。縫い目の相手は、そのまとまりの中で決まります。
- 重ね着: 着せ終わった服は、ほかの服を着せるときに「動かない障害物」になります。内側の服から順に着せます。ほかの服を着せると、それまでの服の経過（コマ）は消え、最後の形だけが残ります。

### ピースの 4 つの状態

| 状態 | 動く | ほかの布が当たる | 縫い目 |
|---|---|---|---|
| 「**アクティブ**」（Active） | ○ | ○ | ○ |
| 「**フリーズ**」（Freeze） | ×（今の場所に止まる） | ○ | ○ |
| 「**型紙から外す**」（Off Pattern） | ×（今の場所に止まる） | ×（すり抜ける） | ○（縫い目は引っぱる） |
| 「**全部オフ**」（Off All） | 計算に入らない | — | ×（縫い目ごと外れる） |

- 使わないピースは、隠す（**H**）のではなく「全部オフ」（Off All）にします。灰色の半透明で表示されます。
- 状態は、左右の対を一緒に切り替えます。片側だけを変えるときは **Ctrl**＋クリックです。

<!-- figure: 図4 ピースの 4 つの状態 -->

### 実行のボタン

| ボタン | 何をするか | 経過のコマ | 止め方 |
|---|---|---|---|
| 「**ライブシム**」（Live Sim） | 置いた形（着せた後は今の形）から縫い合わせ、止めるまで回り続ける。**Ctrl＋ドラッグ**で布をつまめる | 残らない（最後の形だけ） | ボタンをもう一度押すか **Esc** |

着せるのも、直してから落ち着かせるのも「ライブシム」です。自動では止まらないので、服が落ち着いたら止めます。「**重力**」（Gravity）は回っている間に切り替えられます。縫い目を先に閉じたいときは、重力を外して回し、閉じてから重力を入れます。

段を追って縫って自動で止まる「**フェーズシム**」（Phase Sim）と、選んだピースだけを動かす「**ローカルシム**」（Local Sim）は、アドオンの設定の「**試験中の機能**」（Experimental Features）をオンにしたときだけ出ます（「着せる（実行）」）。

#### 今の形から続ける

- 2 回目以降の「ライブシム」、「AC9 Cloth Retopo へ渡す」、服の採寸は、今の服の形を使います。経過のコマを再生しているときは、**画面に出ているコマ**を使います。押す前に、最後のコマになっているかを確かめます（**Shift＋→** で最後のコマ）。
- 途中のコマの形を手で直したいときは、そのコマで「**手で直す**」（Fix by Hand）を押します。そのコマが服の形そのものになり、編集モードやスカルプトで直せます。直した後に「ライブシム」を押すと、直した形から続きます。

<!-- figure: 図6 計算の流れ -->

### 保存されるもの

| もの | 保存される場所 |
|---|---|
| 型紙のデータ・置き方・設定 | .blend の中 |
| 着た服の最後の形 | .blend の中 |
| 経過のコマ（タイムラインで再生できるもの） | 保存した .blend の隣の `AC9_ClothSim_jobs` フォルダ |

- **シミュレーションの前に .blend を保存します。** 保存していないと、経過は一時フォルダに作られ、あとで再生できません。
- .blend だけを別のパソコンに渡しても、最後の形は見えて、そこから続けられます（経過の再生だけはできません）。
- 「**キャッシュを削除**」（Delete Cache）（AC9 Run のボタン）で消した経過は、戻せません。

### 結果の見方

- **同じ設定でも、計算のたびに仕上がりが少し変わります。** 1 回の結果だけで良し悪しを決めないでください。
- 赤い塗りは「異常の候補」（体に入っている所、布どうしが交わっている所、落ち着いていない所など）です。そのまま不良という意味ではありません。
- 異常を見張る設定（「**異常を検出**」（Watch for Anomalies）、日本語表示では「異常を検出」）は、既定ではオフです。使うときは「ライブシム」の前に入れます。

## 困ったとき

### まずここを見る（よくあるつまずき）

| 困っていること | 原因と直し方 |
|---|---|
| サイドバーに「AC9 Cloth Sim」のタブが無い | Preferences の Add-ons で **AC9 Cloth Sim** がオンか。マウスを 3D ビューポートの上に置いて **N** を押したか。入れた直後なら Blender を起動し直す。 |
| 「ライブシム」を押しても何も動かない | 最初は計算の準備で、しばらく動かないように見えます。進み具合の文が出ていれば、もう一度押さずに待ちます（もう一度押すと止まります）。 |
| 実行のボタン（「**ライブシム**」（Live Sim）など）が見つからない | サイドバーではなく、右下の Properties エディタの **Tool** タブにあります。Properties が Render など別のタブになっていないかを見ます。 |
| キーボードのショートカットが効かない | 日本語入力（IME）がオンになっていないか。カーソルが操作したいエリアの上にあるか。 |
| AC9 の道具が道具の列から消えた | 編集モードに入っていないか（**Tab** でオブジェクトモードに戻す）。「**セットアップ**」（Setup）の「**型紙のツール**」（Pattern Tools）がオフになっていないか。 |
| 型紙のピースが **G**／**R**／**S** で動かない | ピースには鍵が掛かっています。「**ピース全体**」（Whole Pieces）の道具で動かします。 |
| ボタンが灰色で押せない | ボタンにカーソルを置くと、押せない理由が出ます。 |
| 真ん中の型紙のビューが回らない | 型紙のビューは、真上から見るだけで回りません。回すのは左の 3D ビューポートです。 |
| 視点を回せない（中ボタンが無い） | 「Edit」→「Preferences」の「Input」で「Emulate 3 Button Mouse」をオンにすると、**Alt**＋左ドラッグで回せます。 |
| ピースが見えない・薄い | 灰色の半透明は「**全部オフ**」（Off All）のピース。赤い輪郭と警告は、Blender の **X** でオブジェクトだけが消えたピース（一覧の「**ピース**」（Pieces）タブから戻せます）。**H** で隠したなら **Alt＋H**。3D ビューポートの右上のオーバーレイが切れていると、AC9 の描く線や色も消えます。 |
| 「**ライブシム**」（Live Sim）で布をつまめない | 押してから少しの間は布が動きません（パソコンによって変わります）。動き始めてからつまみます。「**フリーズ**」（Freeze）や「オフ」のピースはつかめません。 |
| 結果の「Result」の欄に `folder gone` と出る | 保存した後に .blend を移動したか、名前を変えました。最後の形は残っていますが、経過の再生はできません。 |
| 新しい版を入れたら「cannot import name …」と出る、画面が説明と違う | Blender をいったん閉じて、起動し直します。 |

### 戻せない操作と注意

- 「**置いた形に戻す**」（Back to Placed）（何も選ばずに）: 服全体の結果を外します。確認が出ます。Ctrl+Z で戻せます。
- 「**ライブシム**」（Live Sim）:「**停止**」（Stop）か **Esc** を押すまで止まりません。経過のコマは残りません。
- 「**キャッシュを削除**」（Delete Cache）: 消した経過のコマは戻せません。
- 「**ライブシム**」（Live Sim）（2 回目から）、「**AC9 Cloth Retopo へ渡す**」（To AC9 Cloth Retopo）、「**服を採寸**」（Measure Garment）: 経過を再生しているときは、どれも画面に出ているコマを使います。タイムラインの位置を確かめてから押します。
- 「**手で直す**」（Fix by Hand）: 経過の再生が止まります。戻すには Ctrl+Z。
- 「**異常を検出**」（Watch）:「**ライブシム**」（Live Sim）を押す前に入れます。
- テスト用の .blend は、別名で保存してから使い、上書きしないでください。
- 赤い塗りは「異常の候補」で、そのまま不良とは限りません。1 回の結果だけで良し悪しを決めないでください。


### うまく動かないとき

| 症状 | まず確かめること | 次の手 |
|---|---|---|
| 「**ライブシム**」（Live Sim）が始まらず「Set the Newton Python in the add-on preferences」と出る | Preferences の「**Newton の Python**」（Newton Python）の指定 | 指定を直して再度押す。 |
| 「**ライブシム**」（Live Sim）が灰色 | 「**体**」（Body）が選ばれているか。「**ガイド検出**」（Detect Guides）をしたか。 | 体を選び、「**ガイド検出**」（Detect Guides）。 |
| 「未配置 ○ 枚は計算から除外」と出る | 3Dに未配置のピースがある。 | 配置済みのピースだけで計算できます。未配置のピースも計算に加えるときは「**配置**」（Place）で置きます。 |
| 「**ガイド検出**」（Detect Guides）で「upright, facing -Y?」と出る | アバターの向きと姿勢 | まっすぐ立って −Y を向いた体にする。 |
| 「**メッシュから**」（From Mesh）のボタンが押せない | 体が「**体**」（Body）に選ばれているか。服のメッシュがアクティブか。 | 体を選び、服のメッシュをアクティブにする。 |
| 「**手で直す**」（Fix by Hand）が出ない | 経過を再生しているか。 | 再生していない（「**ライブシム**」（Live Sim）の後など）ときは、押さずにそのままスカルプトで直せる。結果が無いなら「**ライブシム**」（Live Sim）で着せる。 |
| BOM の縫い目が自分自身や別の服のピースに付いている | 「**セットアップ**」（Setup）の服のまとまりの行（オレンジは確かでない分け方）。 | 「**BOM から縫い目を更新**」（Update BOM Seams）。手動で分けた服分類は保持します。必要な分類訂正はピースを選んでF3の「選択から服」。 |
| 「**縫い目へ寄せる**」（Part to Seam）、「**帯を縁に載せる**」（Band on Edge）、「**整える**」（Settle）が灰色 | ピースを選んでいるか。置いてあるか。着た服の一部ではないか。 | 置いてから押す。着た服のピースは「**置いた形に戻す**」（Back to Placed）してから押す。 |
| 布が布を突き抜けたまま戻らない | 「**ライブシム**」（Live Sim）中か。 | 「**ライブシム**」（Live Sim）で Ctrl＋ドラッグの間に**Alt**を押してすり抜けさせ、正しい側へ戻す。 |
| 赤が出ない | 「**オーバーレイ**」（Overlays）の目のボタンと「**問題**」（Problems）がオンか。「**異常を検出**」（Watch）を「**ライブシム**」（Live Sim）の前に入れたか。 | 入れ直して「**ライブシム**」（Live Sim）。 |
| 型紙を直したら「changed outside the drafting tools」のようなエラー | 型紙データを JSON で直接変えると、服へ写せません。 | 型紙の道具で直すか、「**置いた形に戻す**」（Back to Placed）して着せ直す。 |
| 縫い目を付け替えたら布が引き寄せられた | 付け替えた所は新しく縫う扱いになります。 | 正常です。続けて「**ライブシム**」（Live Sim）。 |
| 衿が裏返る、つなぎ目がねじれる | 役割と縫う順番（「**ピースの役割**」（Piece Roles））、置き方 | 「**役割を提案**」（Propose Roles）を確かめる。手で直すなら「**手で直す**」（Fix by Hand）を押してからスカルプトで。 |
| 服が最初から崩れる（腰まで落ちる） | **Esc** で止めて、どの段か確かめる | 縫い目の向き（「**向きを反転:**」（Flip the direction of））と置き方を確かめる。 |
| 結果が回ごとに違う | 同じ設定でも揺れます。 | 1 回で決めず、何度か回して見る。 |
| 結果の形が保存されていない | 「**AC9 服**」（AC9 Garment）の「**結果**」（Result）の `Shape:` の行 | .blend を保存する（Ctrl+S）。 |
| 「**ピース編集**」（Edit Pieces）でピースの内側を引いても、ピースが動かない | ピースごと動かすのは別の道具。 | 「**ピース全体**」（Whole Pieces）に持ち替える（「**型紙**」（Pattern）パネルの「**変形**」（Transform））。 |
| 型紙を直したのに、着た服や置いた形が変わらない。「**3D を更新**」（Update 3D）が赤い | 「**AC9 実行**」（AC9 Run）の「**編集を 3D に写す**」（3D Follows Edits）が外れている。 | 「**3D を更新**」（Update 3D）を押すか、「**編集を 3D に写す**」（3D Follows Edits）を押し直す。 |
| 図形を穴にできない（「**穴に変換**」（Convert to Hole）が断られる） | 図形が閉じているか。外周に触れていないか。ほかの穴と重なっていないか。折り・ゴムが付いていないか。 | 図形を外周から離す、折り・ゴムを外す。 |
| 画面の表記が、この資料と違う | アドオンが古いまま読み込まれている。 | Blender を再起動する。 |

お知らせいただくときは、押したボタン、入れた値、状態表示の `done:` の行（または `stopped` とエラー文）、「**ログ**」（Log）の内容、保存した .blend を添えてください。
